# Коли Світло — зеркало графиков отключений

Публикует графики отключений электроэнергии в Украине в одном формате на
[koly-svitlo.web.app](https://koly-svitlo.web.app/v1/index.json).

Отдельный репозиторий от приложения по одной причине: крон гоняется каждые 10 минут
(~4300 запусков в месяц), а бесплатные минуты GitHub Actions не расходуются только на
публичных репозиториях. Данные здесь и так публичные — это графики, которые операторы
сами публикуют у себя.

## Зачем зеркало, если источники открыты

- **Кеш-заголовки.** jsDelivr отдаёт апстрим с `max-age=604800` — телефон держал бы
  недельный график отключений. Здесь `max-age=300`.
- **Один формат.** Каждый оператор публикует своё: ДТЕК — объект `DisconSchedule`,
  Миколаїв — REST API с получасовыми слотами. Адаптеры в `tools/mirror/sources/`
  приводят всё к одной схеме, чтобы приложение не знало, из какой области данные.
- **Валидационный шлюз.** Сломанный файл хуже устаревшего: всё, что не проходит
  `validate()`, не затирает прошлую рабочую копию.

## Что где

```
tools/mirror/mirror.mjs      оркестратор: обходит регионы, валидирует, пишет в firebase/public/v1
tools/mirror/regions.mjs     реестр 26 регионов со статусами
tools/mirror/sources/        адаптеры под конкретных операторов
tools/mirror/probe.mjs       сторож: сообщает, когда сезонный регион начал публиковать график
firebase/public/v1/          то, что раздаётся приложению
```

## Локально

```bash
node tools/mirror/mirror.mjs           # обновить все регионы
node tools/mirror/mirror.mjs mykolaiv  # только один
node tools/mirror/probe.mjs            # проверить сезонные регионы
node tools/mirror/probe.mjs --selftest # убедиться, что детектор ещё видит настоящий график
```

## Статусы регионов

`live` — адаптер работает · `seasonal` — оператор публикует график только во время
ограничений, вне сезона парсить нечего · `blocked` — сайт не отдаёт данные автоматически ·
`noFeed` — нет машиночитаемого графика (PDF, картинки, поиск по лицевому счёту) ·
`occupied` — графиков не существует.

Статусы уезжают в `index.json`, приложение читает список оттуда — регион можно включить
или выключить без релиза в App Store.
