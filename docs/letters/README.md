## Порядок

1. **Суми** — найвужче прохання з усіх. Дані вже готовий JSON, заважає лише їхній власний
   `robots.txt`. Найбільша віддача на один лист.
2. **Прикарпаття** — файл уже існує і вже машиночитний, просимо лише змінити день публікації.
   Відмовити на таке важко. Заодно це робочий приклад, на який посилаються решта листів.
3. **Волинь** — найсильніший аргумент: після рішення НКЦК щодо Telegram у них не лишилось жодного
   придатного каналу, і їхні споживачі єдині в Україні без жодного застосунку.
4. **Чернівці, Вінниця, Кіровоград** — зняти блокування. Це рішення людини, тож людина може його
   і змінити.
5. **Львів, Полтава** — без пошти, через треті канали, тому довше.
6. **Закарпаття** — найдешевше: одне речення у відповідь. Але й виграш найменший.

## Що спільного в усіх листах

- Сказано, що ми **не обходимо** захист сайтів і не читаємо приватні API застосунків. Це головна
  причина писати замість того, щоб просто взяти.
- Названо `User-Agent: svitlo-mirror/1.0` — оператор іде дивитися логи, і там усе має збігатися.
- Запропоновано частоту не частіше одного запиту на 15 хвилин і готовність припинити на вимогу.
- Постанова НКРЕКП №349 від 26.03.2022 згадана **описово**: інформація про перерви актуалізується
  щогодини. Це перевірений факт — Черкаси самі посилаються на неї на своїй сторінці. Ширші
  посилання на Кодекс систем розподілу не робимо: потрібна норма не підтверджена, а хибне
  цитування закону в першому ж листі коштує довіри.
- Підпис без телефону й пошти — підставте, що вважаєте за потрібне.
