# Лист до ПрАТ «Львівобленерго»

**Кому:** пошти у відкритому доступі немає (`loe.lviv.ua` віддає заглушку) — через контакти на
`poweron.loe.lviv.ua`, або через Львівську ОВА (`loda.gov.ua`) та Міненерго (`mev.gov.ua`), які
зазначені партнерами на їхньому ж сайті.
**Просимо:** додати час до вже наявного публічного API — не створювати новий.

---

**Тема:** Прохання додати часовий вимір до наявного публічного API графіків

Доброго дня!

Звертаюсь як розробник «Коли Світло» — безкоштовного застосунку без реклами, який показує людям
графіки погодинних відключень, опубліковані самими операторами.

У вас уже є публічний API `power-api.loe.lviv.ua` — він віддає `blog_gpvs`, `city_gpvs`,
`street_gpvs`, тобто прив'язку адрес до черг. Це зроблено добре і саме так, як треба.

Бракує одного: годин. Самі інтервали відключень публікуються лише зображенням, а з картинки
графік можна прочитати тільки з ризиком помилки. Ми такого не робимо принципово: помилка в
графіку означає, що людина повірить і залишиться без вечора.

**Прохання: додати до вашого ж API часовий вимір — «черга/підчерга → інтервали відсутності
електропостачання».** Це доповнення до наявної системи, а не нова система.

Якщо це неможливо — нам цілком підійде звичайний файл (JSON, CSV або XLSX) за сталою адресою, що
оновлюється при кожній зміні ГПВ. Робочий приклад такого файлу вже існує в Україні:
`oe.if.ua/uk/schedule_archives` в АТ «Прикарпаттяобленерго».

З нашого боку зобов'язуємось: підписаний `User-Agent`, частота не частіше одного запиту на 15
хвилин або будь-яка інша на ваш розсуд, зазначення вас джерелом даних, негайне припинення на вашу
вимогу.

Ідеться про інформацію, яку ви вже публікуєте: згідно з постановою НКРЕКП №349 від 26.03.2022
інформація про перерви в електропостачанні актуалізується щогодини. Прохання не про нові дані, а
про придатну для автоматичного зчитування форму вже наявних.
