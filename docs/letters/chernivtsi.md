машиночитний файл (JSON, CSV, XLSX) за сталою адресою.**

Будь-який із варіантів нас влаштує:

1. файл із графіком за сталою адресою, що оновлюється при зміні ГПВ;
2. виняток у налаштуваннях захисту для `User-Agent: svitlo-mirror/1.0`;
3. письмове підтвердження щодо будь-якого іншого вашого офіційного джерела.

припинення на вашу вимогу.
