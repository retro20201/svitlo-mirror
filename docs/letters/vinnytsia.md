**Тема:** Прохання про доступ до графіків погодинних відключень

Доброго дня!

Звертаюсь як розробник «Коли Світло» — безкоштовного застосунку без реклами, який показує людям
графіки погодинних відключень, опубліковані самими операторами. Офіційним застосунком жодного
оператора ми не є.

Вінницька область — одна з небагатьох, яку ми не можемо додати взагалі. Ваш сайт `voe.com.ua`
відповідає 403 на будь-який запит ззовні, включно з `robots.txt`. Це означає, що ми не можемо
навіть дізнатися, що саме ви дозволяєте читати, — правило блокування закриває і сам файл правил.

Ми не обходимо захист сайтів і не читаємо приватні API застосунків. Саме тому пишемо.

**Прохання: дозволити доступ до однієї адреси — сторінки або файлу з графіком погодинних
відключень — для одного ідентифікованого клієнта.**

Нам підійде будь-який із варіантів:

1. машиночитний файл (JSON, CSV, XLSX) за сталою адресою, що оновлюється при зміні ГПВ;
2. виняток у налаштуваннях захисту для нашого `User-Agent: svitlo-mirror/1.0`;
3. письмове підтвердження, що ми можемо використовувати як джерело інший ваш офіційний канал.

З нашого боку зобов'язуємось: частота не частіше одного запиту на 15 хвилин, зазначення вас
джерелом даних у застосунку, негайне припинення використання на вашу вимогу.

Ідеться про інформацію, яку ви вже публікуєте для споживачів: згідно з постановою НКРЕКП №349 від
26.03.2022 інформація про перерви в електропостачанні актуалізується щогодини. Зараз ця
інформація недоступна нікому, хто хотів би донести її до ваших же споживачів у зручнішому вигляді.
